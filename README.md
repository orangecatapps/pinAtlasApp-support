## Frequently Asked Questions

* **How do I restore my Pro purchase?**
  Go to Settings, tap the Paywall or Upgrade option, and tap "Restore Purchases".
* **Is my data backed up?**
  Pin Atlas stores all collection data locally on your device. You can export a full backup zip file via *Settings > Data Management > Export Collection*.
* **How do I remove the background from pin photos?**
  When adding or editing a pin photo, tap the "Remove background" button to instantly isolate the pin using on-device AI.
